### Dockerfile
    애플리케이션을 실행하기 위해 필요한 OS 환경, 런타임, 빌드된 실행 파일, 실행 명령어 등을 다루는 텍스트 파일이다.
    코드로 명시하기 때문에 동일한 다른 곳에서 빌드해도 동일한 실행 환경을 재현할 수 있다.

### 이미지
    Dockerfile을 빌드하면서 생성된 읽기 전용 템플릿으로, Dockerhub를 통해 다른 서버로 쉽게 배포할 수 있다.

### 컨테이너
    이미지를 바탕으로 실제 메모리에 올려 실행한 가상 프로세스이다.
    여러 컨테이너가 서로 간섭하지 않은 채 동작하며, 필요할 때마다 하나의 이미지로부터 여러 개의 컨테이너를 생성하거나 삭제할 수 있다.

### AWS
    아마존이 운영하는 클라우드 컴퓨팅 플랫폼으로, 필요한 만큼 빌려쓰고 사용한 만큼 비용을 지불하는 방식이다.

### EC2
    AWS에서 제공하는 가상 서버 서비스이다. 원하는 사양으로 애플리케이션 서버를 구동할 수 있다.

### API 호출 시 IP 주소와 Port 역할
    외부 클라이언트가 API를 호출하면 특정 EC2의 위치를 나타내는 고유한 주소인 IP를 통해 해당 서버에 도착한다.
    이후 Port를 통해 네트워크 요청을 알맞은 애플리케이션 프로세스로 전달시킨다.

### 서버 외 요소
    도메인을 도입하여 복잡한 IP 주소 대신에 쉽게 접근할 수 있다.
    트래픽이 급증하는 경우 수요 변화에 맞춰 서버 개수를 자동으로 늘리거나 줄이는 오토 스케일링 방식이 있다.
